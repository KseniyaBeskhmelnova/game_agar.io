# 🟢 OpenGL Game

Проект — реализация игры в стиле Agar.io с использованием **OpenGL**. Игрок управляет шаром с помощью клавиш управления курсором, поглощая более мелкие шарики, чтобы увеличиваться в размерах.

## Модификация

Реализован алгоритм поиска ближайшей "еды", то сеть шар движется сам без участия игрока.
